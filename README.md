# 🐴 Horse Feeding Tracker

A simple web application for tracking who fed the horse and when — built for family use and designed to be easy, secure, and reliable.

---

## 🌐 Live Demo

👉 [Click here to use the app](https://horse-feeding-tracker.onrender.com/index.html)

---

## ✨ Features

- ✅ Select your name from a list
- ✅ Enter a password to confirm your identity
- ✅ Record the current time and date
- ✅ View today's feeding history
- ✅ View full historical log
- ✅ Mobile-friendly design
- ✅ Passwords stored securely using environment variables
- ✅ Fully deployed on Render with SQLite backend

---

## 🛠️ Built With

- **Node.js + Express**
- **SQLite** (temporary database storage on Render)
- **HTML, CSS, JavaScript**
- **Render.com** (for full-stack deployment)

---

## 📚 How to Use

1. Open the [live site](https://horse-feeding-tracker.onrender.com/index.html)
2. Select your name from the dropdown
3. Enter your personal password
4. Click **“I Fed the Horse”**
5. You'll see your name and time appear in the **"Feedings Today"** section
6. To view the full history, click **“View Full History”**

---

## 🔐 Security Notes

- All usernames and passwords are stored securely via environment variables.
- This app is private-use only and not intended for public registration.
- If someone wants to use the same system, they can clone the repo and provide their own `.env` file.
